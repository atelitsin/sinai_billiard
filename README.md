# sinai_billiard

Симуляция бильярда Синая для исследования по математической физике: event-driven
динамика (столкновения находятся аналитически, без накопления численной ошибки),
визуализация/анимация движения, и инструментарий для сбора и анализа данных о
хаотическом поведении.

## Структура

- `sinai_billiard/geometry.py` — таблица бильярда: стенки (отражающие или
  периодические) и круглые рассеиватели.
- `sinai_billiard/simulation.py` — event-driven симуляция (точное аналитическое
  разрешение столкновений со стенками и дисками).
- `sinai_billiard/visualize.py` — статичные графики траекторий, анимация,
  сечения Пуанкаре.
- `sinai_billiard/analysis.py` — показатель Ляпунова (метод Беннеттина),
  статистика столкновений, гистограмма эргодичности, автокорреляция скорости,
  MSD/коэффициент диффузии.
- `sinai_billiard/experiments.py` — построение разных геометрий таблицы,
  параметрические свипы, экспорт в CSV.
- `notebooks/demo.ipynb` — основной ноутбук: строит все таблицы, анимирует
  движение, считает метрики хаотичности, экспортирует данные в `data/`.
- `tests/test_physics.py` — sanity-проверки физики (сохранение скорости,
  непроникновение в диск/за стенки, знак показателя Ляпунова).

## Геометрии

- `sinai_square` — классический бильярд Синая: квадрат со стенками-отражателями
  и круглым рассеивателем в центре.
- `sinai_torus` — исходная конструкция Синая: тор (периодические границы) с
  выколотым диском.
- `multi_disk` — произвольная конфигурация из нескольких дисков.
- `integrable_square` — квадрат без рассеивателя, для контраста с интегрируемым
  (нехаотическим) случаем.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name sinai_billiard --display-name "Python 3 (sinai_billiard)"
jupyter notebook notebooks/demo.ipynb
```

Проверить физическое ядро отдельно:

```bash
python tests/test_physics.py
```

## Что нужно сделать самостоятельно

Ноутбук считает метрики и строит графики, но **выводы и интерпретацию
результатов нужно написать самому** — в конце ноутбука есть раздел с
наводящими вопросами (без готовых ответов).
